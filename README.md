## Course Content

This course is split into several sections covering modern implementations of design patterns and SOLID principles.

| Section | Details |
|----------|----------|
| **Introduction** | Course overview and introduction to design patterns |
| **SOLID Design Principles** | Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation and Dependency Inversion principles |
| **Builder** | Object construction through fluent and faceted builders |
| **Factories** | Factory Method, Abstract Factory and functional factories |
| **Prototype** | Object cloning and copying techniques |
| **Singleton** | Singleton and Multiton implementations |
| **Adapter** | Adapting incompatible interfaces |
| **Bridge** | Separating abstraction from implementation |
| **Composite** | Building tree-like object structures |
| **Decorator** | Dynamically extending object behavior |
| **Facade** | Simplifying complex subsystems |
| **Flyweight** | Sharing common state efficiently |
| **Proxy** | Controlling access to objects |
| **Chain of Responsibility** | Passing requests through chains of handlers |
| **Command** | Encapsulating requests as objects |
| **Interpreter** | Representing and evaluating grammars |
| **Iterator** | Traversing collections and custom data structures |
| **Mediator** | Centralizing communication between objects |
| **Memento** | Capturing and restoring object state |
| **Observer** | Event-driven object communication |
| **State** | Managing behavior through internal state |
| **Strategy** | Encapsulating interchangeable algorithms |
| **Template Method** | Defining algorithm skeletons |
| **Visitor** | Adding operations without modifying object structures |
| **Pattern Variations** | Modern C++ implementations and alternatives |

## Goals of this Course

- Learn and apply the SOLID design principles.
- Implement design patterns using Modern C++ features.
- Recognize common design problems and their solutions.
- Explore practical examples and real-world use cases.
